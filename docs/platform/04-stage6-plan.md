# Этап 6. План

12 октября 2026. Локально, без облака, платных подключений и реальных данных.

## Что делаю

1. **2FA администратора.** Плагин `twoFactor` из Better Auth 1.7.7: приложение-аутентификатор (TOTP) и одноразовые резервные коды.
   - Администратор без 2FA после входа может только настроить её, остальные разделы закрыты.
   - Вход с 2FA проходит в два шага, «доверенные устройства» отключены.
   - Восстановление доступа: резервный код; сброс 2FA другим администратором; консольная команда на сервере, если администратор один. Все действия записываются в журнал.
   - Сброс пароля 2FA не отключает.
2. **Сессии.** Анализ хранения токена в базе: что даёт подпись cookie, чего не даёт, варианты и их последствия. Механизм без вашего согласия не меняю.
   - Новые возможности: смена пароля с закрытием остальных сессий, завершение всех сессий пользователя администратором.
   - Тесты: отзыв сессии, истечение срока, блокировка, смена пароля, подделка cookie по токену из базы.
3. **Файлы.**
   - Резюме открывается клиенту, только если администратор явно выбрал конкретный файл в представлении. Новая загрузка никому не видна автоматически.
   - PDF с активным содержимым (скрипты, автозапуск, запуск программ, вложенные файлы, XFA) отклоняется.
   - Подготовлена антивирусная проверка через ClamAV (свободная программа на своём сервере, не внешний сервис). Пока ClamAV не подключён, работа с резюме разрешена только при явно выключенной проверке: это видно в настройках и в отчёте.
4. **Экраны.** Переношу разметку и стили демоверсии в кабинеты на реальных данных: одна страница `/app`, без фреймворка, тот же код отрисовки, данные через API.
5. **Показатели.** Сводка по клиентам для администратора и тесты фильтров и изоляции.
6. **Проверка публикации и истории репозитория** на секреты и персональные данные. Настройки публикации не меняю.
7. **Отчёт и список блокирующих задач** перед запуском.
