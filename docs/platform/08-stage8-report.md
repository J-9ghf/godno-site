# Этап 8. Отчёт: удаление чатов

12 октября 2026.

## Что сделано

Чатов в рабочей платформе не было с этапа 5: нет таблицы, API и экранов. На этом этапе по списку из аудита (раздел 1.5 документа `01-audit-and-architecture.md`) переписка убрана из демоверсии `prototypes/ikr-platform.html`, а её стили — и из платформы.

| Что | Удалено |
|---|---|
| Данные | массив `messages` в демо-данных, таблица `messages` в списке таблиц, упоминание в комментарии про Realtime |
| Слой данных | `getThreads`, `getMessages`, `sendMessage`, тип события `message` в ленте и журнале |
| Экраны | раздел «Сообщения» в меню всех ролей, экран `tMessages`, вкладка «Сообщения» в карточке клиента, строка «Сообщения» в матрице ролей |
| Кнопки | «Переписка по заявке», «Переписка», «Сообщения» в карточке кандидата, «Новая тема по кандидату» |
| Обработчики | `openThread`, `newThread`, формы `msgForm` и `threadForm`, отправка по Ctrl+Enter |
| Стили | `.msgs`, `.threads`, `.thread`, `.conv-*`, `.bub` — в демоверсии и в `platform.css` |
| Сохранённые данные | ключ хранилища браузера демоверсии сменён на `ikr-platform-db-v3`: старые сохранённые данные с перепиской не подхватываются |

**Остались, как требовалось:** комментарий рекрутера для клиента, обратная связь по интервью и кандидатам, причины отказа, история этапов, журнал действий.

## Тесты

Новый тест — `demo-prototype.test.ts`, 5 тестов:
- в коде демоверсии нет следов переписки;
- для каждой роли (клиент-компания, клиент-семья, менеджер, администратор) в браузере открываются все разделы меню, первые карточки и все вкладки карточки клиента;
- нет ошибок JavaScript и нет текстов «Сообщения», «Переписка», «Новая тема».

Тест проверен на исходной версии демоверсии: там все 5 тестов падают, на новой проходят.

`ui.test.ts` (кабинеты платформы) после удаления стилей — 7 из 7.

**Поиск по коду** платформы, сайта и демоверсии не находит остатков переписки. Слово «сообщения» осталось только в смысле «сообщения об ошибках».

## Известные ограничения

- **Опубликованная демоверсия (артефакт) не обновлялась** и пока показывает старую версию с перепиской. Обновить её по той же ссылке — ваше решение. Это меняет содержимое, а не настройки доступа.
- Разделы демоверсии второй очереди (заявки, интервью, документы, услуги) остаются только в демоверсии.
