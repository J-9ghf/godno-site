# Резервное копирование и проверка восстановления

## Что и как копируется

| Что | Основная защита в облаке | Дополнительно |
|---|---|---|
| База PostgreSQL | Автоматические копии Managed PostgreSQL и восстановление на момент времени (настроить срок хранения не меньше 7 дней) | Еженедельная логическая копия `scripts/backup.sh` в отдельный закрытый бакет с шифрованием |
| Файлы (резюме, документы) | Версии объектов в бакете и правило хранения удалённых версий на срок хранения копий | Репликация в отдельный бакет — по решению после оценки стоимости |
| Настройки и секреты | Lockbox (хранилище секретов) | Резервный доступ у ответственного лица |

Условия хранения копий (срок, размещение в России, шифрование) нужно сверить с договором провайдера до запуска.

## Сделать копию

```bash
DATABASE_OWNER_URL=postgres://ikr_owner:...@хост:порт/ikr ./scripts/backup.sh /защищённая/папка
```

Скрипт создаёт архив `pg_dump` (права файла 600), проверяет, что архив читается, и записывает контрольную сумму.
Копия содержит персональные данные: хранить только в закрытом месте, удалять по сроку хранения.

## Проверить восстановление (раз в квартал и после изменений схемы)

```bash
ADMIN_URL=postgres://postgres@хост:порт/postgres \
SOURCE_URL=postgres://ikr_owner@хост:порт/ikr \
./scripts/restore-check.sh /защищённая/папка/ikr-....dump
```

Скрипт проверяет контрольную сумму, разворачивает копию в отдельную временную базу, сверяет список миграций
и число строк в основных таблицах с исходной базой, затем удаляет временную базу. Рабочая база не меняется.
Если база менялась после создания копии, расхождение ожидаемо: проверяйте копию, сделанную непосредственно перед проверкой.

Запишите в журнал проверок: дату, файл копии, результат, кто проверял.

**Проверено локально 12 октября 2026:** копия базы с вымышленными данными развёрнута, все таблицы совпали с исходной
(миграции 4, компании 2, кандидаты 6, представления 6, история этапов 12).

## Восстановление файлов

Для объекта в бакете с включёнными версиями — восстановить нужную версию через консоль или API провайдера.
Порядок будет описан на этапе развёртывания, после выбора настроек бакета.
