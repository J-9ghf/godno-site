# Как развернуть платформу ИКР на новой машине Selectel

Инструкция для человека без опыта администрирования. Займёт около часа, из них 15–20 минут — ожидание.
Названия пунктов в панели Selectel могут немного отличаться от написанных здесь — ищите похожие.

Что получится в конце: сайт и кабинеты открываются по вашему адресу (например, `https://ikr.example.ru`),
данные хранятся на этой машине, файлы кандидатов — в хранилище Selectel, каждую ночь делается зашифрованная копия базы.

## Что понадобится

- доступ к панели Selectel с пополненным балансом;
- доступ к настройкам домена (там, где покупали домен);
- доступ к репозиторию на GitHub (`j-9ghf/godno-site`);
- менеджер паролей (или бумага и сейф) — для паролей и ключа копий;
- 20 минут без спешки на шаги 5–7.

## Шаг 1. Создайте машину (облачный сервер)

В панели Selectel: **Облачная платформа → Серверы → Создать сервер**.

| Что выбрать | Значение |
|---|---|
| Образ (операционная система) | Ubuntu 24.04 LTS |
| Процессор | 2 vCPU |
| Память | 4 ГБ |
| Диск | 40 ГБ, SSD |
| Сеть | с публичным IP-адресом |
| Доступ | пароль пользователя root (сохраните в менеджер паролей) |

После создания запишите **IP-адрес** машины (четыре числа через точку).

## Шаг 2. Создайте хранилище для файлов и копий

В панели: **Объектное хранилище → Создать контейнер (бакет)**. Нужно два, оба **приватные** (не публичные):

| Имя | Для чего |
|---|---|
| `ikr-files` | резюме и документы кандидатов |
| `ikr-backup` | ночные копии базы |

Затем создайте ключ доступа к хранилищу: **Управление доступом → Сервисные пользователи → Добавить**
(роль с доступом к объектному хранилищу), затем у этого пользователя **S3-ключи → Добавить ключ**.
Появятся два значения — **Access key** и **Secret key**. Сохраните оба в менеджер паролей.
Secret key показывают один раз.

Там же, в настройках хранилища, посмотрите **адрес S3 (endpoint)** и **регион**. Обычно это
`https://s3.ru-1.storage.selcloud.ru` и `ru-1` — тогда при установке можно просто нажимать Enter.

## Шаг 3. Направьте адрес сайта на машину

У регистратора домена добавьте запись:

| Тип | Имя | Значение |
|---|---|---|
| A | `ikr` (или `@`, если сайт на основном домене) | IP-адрес машины из шага 1 |

Запись начинает работать через 15–60 минут. Пока ждёте, можно делать шаги 4–5.

## Шаг 4. Подключитесь к машине

- **Windows:** откройте «PowerShell». **Mac:** откройте «Терминал».
- Напишите (вместо `1.2.3.4` — IP-адрес машины) и нажмите Enter:

```
ssh root@1.2.3.4
```

На вопрос «Are you sure you want to continue connecting» напишите `yes`. Затем введите пароль root
(при вводе символы не видны — это нормально).

Дальше все команды вставляются в это окно. Вставить: правая кнопка мыши (Windows) или Cmd+V (Mac).

## Шаг 5. Скачайте платформу

Машине нужно разрешение читать репозиторий. Вставьте:

```
ssh-keygen -t ed25519 -N "" -f /root/.ssh/ikr_github -C ikr-server && cat /root/.ssh/ikr_github.pub
```

Появится строка, начинающаяся с `ssh-ed25519`. Скопируйте её целиком. На GitHub откройте репозиторий
→ **Settings → Deploy keys → Add deploy key**: название `ikr-server`, в поле Key вставьте строку,
галочку «Allow write access» **не** ставьте → **Add key**.

Затем вставьте на машине:

```
apt-get update && apt-get install -y git
GIT_SSH_COMMAND="ssh -i /root/.ssh/ikr_github -o StrictHostKeyChecking=accept-new" git clone -b claude/sharp-goodall-iy3098 git@github.com:j-9ghf/godno-site.git /opt/ikr/app
git -C /opt/ikr/app config core.sshCommand "ssh -i /root/.ssh/ikr_github"
```

## Шаг 6. Установите

```
bash /opt/ikr/app/deploy/supabase-single-vm/scripts/install.sh
```

Установка задаст вопросы:

| Вопрос | Что ответить |
|---|---|
| Домен сайта | адрес из шага 3, без `https://` (например, `ikr.example.ru`) |
| Адрес S3, регион | Enter (если в шаге 2 значения совпали), иначе — значения из панели |
| Бакет для файлов кандидатов | Enter (`ikr-files`) |
| Access key, Secret key | значения из шага 2 (Secret key при вводе не виден) |
| Бакет для копий базы | Enter (`ikr-backup`) |
| Создать ключ для копий? | Enter (да) |

**Ключ для копий.** Установка покажет три строки между линиями. Сохраните их **все** в менеджер паролей
под названием «ИКР — ключ копий». Без этого ключа восстановить данные из копии нельзя, а на сервере его
не будет. Когда сохраните — напечатайте `СОХРАНИЛ`.

Дальше установка всё делает сама: 10–15 минут. В конце должно быть написано:

```
сайт работает: https://ikr.example.ru (...)
ГОТОВО.
```

Если написано «ПРОБЛЕМА» и «Сайт не отвечает» — чаще всего адрес из шага 3 ещё не заработал.
Подождите 30 минут и запустите ту же команду установки ещё раз: она безопасна, готовое не трогает.

## Шаг 7. Создайте первого администратора

```
bash /opt/ikr-supabase/scripts/create-admin.sh ваша@почта.ru "Имя Фамилия"
```

Появится ссылка. Она открывается **один раз** и действует **72 часа**. Откройте её в браузере, укажите
имя и придумайте пароль (не короче 10 символов).

**Код для входа.** У администратора вход в два шага: пароль, затем код. Пока почта не подключена,
код не приходит письмом — его показывает команда на машине:

```
bash /opt/ikr-supabase/scripts/login-code.sh ваша@почта.ru
```

Код действует 10 минут. Когда подключим почту, код будет приходить письмом.

## Шаг 8. Пригласите клиентов

Войдите как администратор → **Пользователи и доступы → Пригласить пользователя**. Пока почта не подключена,
ссылка-приглашение появится на экране с кнопкой «Скопировать». Отправьте её человеку сами
(например, в мессенджере). Ссылка видна только вам, действует 72 часа и открывается один раз.
Если ссылка потерялась — отзовите приглашение и создайте новое.

## Что дальше происходит само

| Что | Когда |
|---|---|
| Копия базы в хранилище `ikr-backup`, зашифрованная вашим ключом | каждую ночь около 03:30 по Москве |
| Удаление копий старше 14 дней | вместе с копией |
| Копия файлов кандидатов в `ikr-backup/files` | вместе с копией |
| Исправления безопасности Ubuntu | автоматически |

## Обновление

**Платформа** (новые функции и исправления): `bash /opt/ikr-supabase/scripts/update-app.sh`.
Скрипт делает копию базы, применяет изменения и проверяет сайт. Если сборка не удалась — сайт продолжает
работать на прежней версии.

**Сервисы Supabase** (раз в 1–3 месяца, версии меняет разработчик): `bash /opt/ikr-supabase/scripts/update.sh`.

**Проверить, что всё работает:** `bash /opt/ikr-supabase/scripts/health.sh`.

## Если что-то пошло не так

| Что видно | Что сделать |
|---|---|
| «Сайт не отвечает» сразу после установки | подождите, пока заработает адрес (шаг 3), и запустите установку ещё раз |
| «Не удалось скачать образы» | Docker Hub временно недоступен или ограничил скачивание; повторите установку через час |
| «Приложение не видит настройки или Supabase» | `journalctl -u ikr-app -n 50` — пришлите вывод разработчику (паролей там нет) |
| Потерялись данные | инструкция [RESTORE.md](RESTORE.md) |
