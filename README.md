# Институт кадровых решений — сайт

Одностраничный сайт кадрового и управленческого бюро. Astro (статическая сборка), без UI-фреймворков, ~4 КБ клиентского JS.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # → dist/
npm run check     # проверка типов
```

## Форма заявки

Форма отправляет `POST` (FormData: `name`, `contact`, `message`) на адрес из переменной окружения:

```bash
PUBLIC_FORM_ENDPOINT=https://… npm run build
```

Подойдёт любой обработчик, принимающий FormData (Formspree, собственный backend, webhook CRM). **Пока переменная не задана, заявки не отправляются** — форма показывает сообщение об этом.

## Структура

```
src/
  data/content.ts          все тексты (дословно от клиента)
  content/legal/*.md       юридические документы — ТОЛЬКО из документов компании
  styles/global.css        дизайн-токены и базовые UI-элементы
  layouts/                 Base, LegalPage
  components/              по компоненту на блок
  scripts/main.ts          reveal, аккордеоны, меню, видео, слайдер, шаги процесса, форма
public/media/              hero.webm / hero.mp4 (без звука), hero-poster.jpg
```

## Что нужно подключить

- **Логотип** — `src/components/Logo.astro` сейчас выводит текстовую заглушку. Положите файл в `public/logo.svg`
  и замените разметку в компоненте (инструкция в комментарии). Основной синий `--c-blue` в `global.css`
  выровнять по цвету логотипа. Favicon — `public/favicon.svg`.
- **Юридические тексты** — вставьте дословный текст в `src/content/legal/privacy.md` и `personal-data.md`,
  удалите `pending: true`. Пока `pending`, страница показывает заглушку и закрыта от индексации.
- **Форма** — `PUBLIC_FORM_ENDPOINT`.

## Дизайн-система

Визуальная логика — Behance-референс: крупный жирный гротеск с синим фрагментом в заголовке, pill-метки,
белые панели на светлом фоне, тонкие вертикальные разделители, синие квадратные «галочки», индикатор шага с прогресс-баром.
Характер — институциональный: строгая сетка, мало элементов, без декора.

**Цвет:** white `#FFFFFF`, black `#0A0C11`, blue `#1447E6`, light blue `#EEF3FF` / `#F4F7FC`. Других цветов нет.

**Шрифт:** Manrope (variable, кириллица), только sans-serif.

| Роль    | Размер        | Начертание | Трекинг |
|---------|---------------|------------|---------|
| Display | 36 → 72 px    | 700        | −0.038em |
| H2      | 32 → 60 px    | 700        | −0.03em |
| H3      | 22 → 30 px    | 700        | −0.02em |
| Lead    | 18 → 21 px    | 500        | −0.01em |
| Body    | 16–17 px      | 450        | 0 |
| Meta    | 13 px         | 600        | 0 |

**Сетка:** контейнер 1360 px, 12 колонок (4 на мобильном), gutter 24/20/16, поля 48/32/20.
**Радиусы:** 8 / 12 / 20 / 28. **Кнопки:** прямоугольные, радиус 12, синие → чёрные на hover.
**Ритм:** Hero (светлый) → О нас (белый) → Подход (светлый, асимметричные панели) → Опыт (белый, editorial-список)
→ Консалтинг (чёрный, два «досье») → Отзывы (светлый, крупная цитата + слайдер) → Процесс (белый, вертикальный, sticky «Шаг N из 5»)
→ FAQ (светлый) → Заявка (синий) → Footer (чёрный).
