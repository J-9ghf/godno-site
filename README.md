# ИКР.Ассистенты — лендинг

Направление Института кадровых решений. Astro (статическая сборка), GSAP + ScrollTrigger для анимаций, привязанных к скроллу; остальное на CSS.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # → dist/
npm run check     # проверка типов
```

| Путь | Что |
|---|---|
| `/` | лендинг ИКР.Ассистенты |
| `/institute/` | прежний сайт Института кадровых решений (без изменений) |
| `/privacy` | политика конфиденциальности (общая) |

## Где что лежит

```
src/data/assistants.ts   ВСЕ тексты лендинга — правки только здесь
src/ikr/*.astro          по компоненту на блок (Header, Hero, Why, Ai, Us, About, Process, Cases, Guarantees, Faq, FinalCta, Footer)
src/layouts/Assist.astro <head>, SEO, JSON-LD, шрифты
src/styles/assist.css    дизайн-токены, типографика, кнопки, исходные состояния анимаций
src/scripts/assist.ts    анимации и интерактив (меню, FAQ, форма, слайдер, мобильный CTA)
public/brand/ikr-logo.png логотип заказчика (обрезаны поля, фон бумаги сделан прозрачным; форма не менялась)
```

## Что нужно заменить

- **Строки с пометкой `// ЧЕРНОВИК`** в `src/data/assistants.ts` — описания, собранные из формулировок ТЗ
  и кейсов (без новых фактов). Заменить дословным текстом из файла со структурой сайта.
- **Плейсхолдеры** (штрихованные рамки на странице):
  - личная история Екатерины в блоке «ИИ и живой ассистент» — `ai.story`;
  - фото и история Екатерины, пять фактов (опыт, ассоциации, сообщество, база, рынок) — `about`;
    фото: заменить `.ph` в `src/ikr/About.astro` на `<img>` (рамка уже с параллаксом);
  - скриншоты переписок — `src/ikr/Cases.astro`, слайдер `.shots__track` (имена и данные — замазать).
- **Отправка формы не подключена**: проверка полей и состояние «Спасибо» работают, данные никуда не уходят
  (`initForm()` в `src/scripts/assist.ts`).

## Дизайн-система

**Цвет** — из логотипа: бумага `#F5F3EF`, графит `#1B1B1D`, тёмно-синий `#142758`;
один цифровой акцент — кобальт `#2E4BFF` (движение, активные состояния, CTA). Без градиентного UI.

**Шрифты:** Inter Tight (variable, кириллица) — заголовки и текст; JetBrains Mono — метки, номера, данные.
Шкала: mega 46→164 px, XL 38→112, L 31→72, M 22→36, lead 18→24, body 16–18. Отрицательный трекинг на крупных размерах.

**Ритм блоков:** Hero (бумага, поток задач) → Зачем (бенто из 4 разных карточек + текст, проявляющийся при скролле)
→ ИИ (тёмный, интерактивная схема) → Почему мы (противопоставление сценариев, список, две зоны услуг)
→ О нас (фото + editorial) → Процесс (синий, горизонтальный pinned timeline на desktop, вертикальный на mobile)
→ Кейсы (карточки с крупным результатом, отзывы, слайдер) → Гарантии (тёмный, щит, 50/50)
→ FAQ → Заявка (панель раскрывается на всю ширину при подлёте) → Footer.

**Анимации:** stagger-появление заголовков по словам, подсветка «в разы больше» с курсором «Ассистент»,
конвейер задач «в работе → готово» через «ворота» ассистента (чистый CSS), счётчики цифр, scroll-reveal,
параллакс, магнитные кнопки и наклон карточек (только мышь). `prefers-reduced-motion` — всё показывается сразу, без движения.

Одностраничный сайт кадрового и управленческого бюро. Astro (статическая сборка), без UI-фреймворков, ~4 КБ клиентского JS.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # → dist/
npm run check     # проверка типов
```

## Форма заявки

Сейчас форма работает **только как интерфейс**: проверка полей и согласия, затем состояние
«Спасибо. Мы свяжемся с вами.». Данные никуда не отправляются — ни CRM, ни почта, ни backend
не подключены (логика — `initForm()` в `src/scripts/main.ts`).

## Что нужно подключить

- **Политика конфиденциальности** — вставьте дословный текст документа в `src/content/legal/privacy.md`
  и удалите `pending: true`. Пока `pending`, страница показывает заглушку и закрыта от индексации.
  Реквизиты и контакты не выдумываются — только из документов компании.
- **Контакты в footer** — добавить, когда будут предоставлены.
- **Отправка формы** — не подключена намеренно.

## Логотип и название

- **Логотип ИКР** (знак + «ИКР») — из оригинального файла заказчика; строка «Институт кадровых решений» из графики убрана
  (кадрирование файла, без перерисовки). `public/brand/mark-dark.png` + `mark-accent.png` — альфа-маски,
  цвета слоёв задаются `--logo-ink` / `--logo-accent` (поверх видео — белый и светло-голубой, на белом — чёрный и синий).
- **«Институт кадровых решений»** — отдельный текстовый элемент (`src/components/Brand.astro`): uppercase, трекинг, тонкая вертикальная линия.
- favicon / apple-touch-icon — знак (бруски) из того же файла.

## Hero-видео

`public/media/hero.webm` + `hero.mp4` — видео заказчика без звука, перекодировано в бесшовную петлю
(последняя секунда растворяется в первую, чтобы при `loop` не было скачка), `hero-poster.jpg` — первый кадр.
Видео — фон всего первого экрана (100svh, `object-fit: cover`), без controls; кроп: desktop 50%, tablet 64%, mobile 60% по горизонтали.

## Дизайн-система

Визуальная логика — Behance-референс, институциональный характер — референсы госсайтов.

**Цвет:** white `#FFFFFF`, black `#0A0C11`, blue `#1447E6`, light blue `#EEF3FF` / `#F4F7FC`
(+ тот же синий на 30 % для неактивных номеров). Других цветов нет.

**Шрифт:** Manrope (variable, кириллица), только sans-serif.

| Роль              | Размер      | Начертание / трекинг |
|-------------------|-------------|----------------------|
| H1 (hero)         | 40 → 92 px  | 700 / −0.045em, ограничен 9.4vh |
| Display (секции)  | 40 → 84 px  | 700 / −0.045em |
| H2                | 34 → 72 px  | 700 / −0.04em |
| H3                | 24 → 38 px  | 700 / −0.02em |
| Большие номера    | 48 → 96 px  | 700 / −0.06em |
| Lead              | 18 → 21 px  | 500 |
| Body              | 16–17 px    | 450 |
| Eyebrow (метки)   | 12 px       | 700 / uppercase / +0.14em |

**Сетка:** контейнер 1360 px, 12 колонок (4 на мобильном), gutter 24/20/16, поля 48/32/20.
**Приёмы:** шапка секции «линия → номер → метка → подпись справа»; крупный editorial-заголовок;
тонкие линии вместо карточек; большие номера; намеренные смещения по сетке (принципы, hero, отзывы).
**Кнопки:** прямоугольные, радиус 12, синие → чёрные на hover.

**Ритм:** Hero (видео на весь экран) → О нас (белый) → Подход (светлый) → Опыт (белый, editorial case list)
→ Консалтинг (светло-голубой) → Отзывы (белый, асимметричная мозаика цитат) → Процесс (светлый, вертикальный timeline)
→ FAQ (белый, строгий accordion) → Заявка (светло-голубой) → Footer (чёрный).
