# Институт кадровых решений — сайт

Одностраничный сайт кадрового и управленческого бюро. Astro (статическая сборка), без UI-фреймворков, ~4 КБ клиентского JS.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # → dist/
npm run check     # проверка типов
```

## Форма заявки

Сейчас форма работает **только как интерфейс**: проверка полей и согласия, затем состояние
«Спасибо. Мы свяжемся с вами.». Данные никуда не отправляются — ни CRM, ни почта, ни backend
не подключены (логика — `initForm()` в `src/scripts/main.ts`).

## Документы

Первоисточник — PDF заказчика (лежат без изменений в `public/docs/`, доступны со страниц документов):

| Ссылка в footer | Страница | Документ (название из PDF) | Текст |
|---|---|---|---|
| Политика конфиденциальности | `/privacy-policy` | Политика в отношении обработки персональных данных | `src/content/legal/privacy.md` |
| Обработка персональных данных | `/personal-data` | Согласие на обработку персональных данных | `src/content/legal/consent.md` |

Тексты перенесены дословно; автотест сверяет текст отрисованной страницы с текстом PDF посимвольно
(без учёта пробелов, маркеров списков и переносов строк). Полужирные фрагменты согласия соответствуют выделению в PDF.
В PDF нет даты документа — на страницах она не выводится.

Реквизиты оператора (`operator` в `src/data/content.ts`) — из текста согласия; выводятся в footer.

**Требует решения владельца документа:** в PDF политики остались значения из шаблона —
e-mail `privacy@thismywebsite.com` (п. 8.3, 8.4, 12.1) и адрес `https://privacy_policy.` (п. 12.3),
веб-сайт в документе указан как `https://yakovlevagency.ru/`; в согласии упоминается сервис Tilda.
На сайте они выведены как есть (без автоссылок: `markdown.gfm = false`).

- **Логотип ИКР** (знак + «ИКР») — из оригинального файла заказчика; строка «Институт кадровых решений» из графики убрана

## Hero-видео

`public/media/hero.webm` + `hero.mp4` — видео заказчика без звука, перекодировано в бесшовную петлю
(последняя секунда растворяется в первую, чтобы при `loop` не было скачка), `hero-poster.jpg` — первый кадр.
Видео — фон всего первого экрана (100svh, `object-fit: cover`), без controls; кроп: desktop 50%, tablet 64%, mobile 60% по горизонтали.

## Дизайн-система

Собственный язык «института»: цветовые поля вместо рамок, индексы разделов, узлы-квадраты,
крупная типографика, асимметрия. Линии — только функциональные (FAQ) и короткие акцентные отрезки.

**Палитра:** navy `#10243A` (поля) / `#0F1D2E` (текст), бумага `#F5F3EE` (фон), белый, туман `#DFE5EA` / `#EBEFF2`,
сланцевый `#4F5F71` (вторичный текст), акцент — глубокий бирюзовый `#0A7A74` (на светлом) / `#4FD1C5` (на navy и видео),
бирюзовая поверхность `#D6ECE9`. Акцент — дозированно: CTA, индексы, номера, узлы, ключевые цифры, hover.

**Шрифт:** Manrope (variable, кириллица), только sans-serif. Шкала — как прежде (H1 до 92 px, display до 84 px, метки 12 px uppercase).

**Графическая система:**
- индекс раздела `▪ 03 / ПОДХОД` + служебная подпись справа (компонент `SectionTag`);
- узел `.node` — маленький квадрат: единица структуры (метки, номера цитат, этапы);
- цветовые поля секций: `.section--white`, `--mist`, `--navy` (тёмное поле пересчитывает токены);
- кейсы — редакционные истории (`CaseStory`): текст + цветовая панель, чередование сторон и поверхностей;
- вертикальная типографика в hero (направления работы).

**Ритм:** Hero (видео, navy-тонировка) → О нас (бумага) → Подход (navy) → Опыт (бумага, истории)
→ Консалтинг (туман, белая и navy поверхности) → Также находили (бумага, 3 колонки) → Отзывы (цитата на navy)
→ Процесс (белый) → FAQ (бумага) → Заявка (navy) → Footer (бумага, реквизиты на туманной полосе).
