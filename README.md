# Институт кадровых решений — сайт

Одностраничный сайт кадрового и управленческого бюро. Astro (статическая сборка), без UI-фреймворков, ~4 КБ клиентского JS.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # → dist/
npm run check     # проверка типов
```

## Форма заявки

Форма отправляет `POST` (FormData: `name`, `contact`, `message`) на адрес из переменной окружения:

```bash
PUBLIC_FORM_ENDPOINT=https://… npm run build
```

Подойдёт любой обработчик, принимающий FormData (Formspree, собственный backend, webhook CRM). **Пока переменная не задана, заявки не отправляются** — форма показывает сообщение об этом.

## Структура

```
src/
  data/content.ts        все тексты (дословно от клиента)
  styles/global.css      токены дизайн-системы, базовые стили, кнопки, reveal
  layouts/Base.astro
  components/            по компоненту на блок страницы
  scripts/main.ts        reveal, аккордеоны, меню, активная навигация, слайдер, форма
```

Тексты правятся только в `src/data/content.ts`.

## Дизайн-система

**Направление.** Государственный институт + консалтинг + editorial. Выразительность за счёт типографики, сетки и пустоты, без декора, иконок и стоковых фото.

**Шрифты** (self-hosted через @fontsource, с кириллицей):
- *Source Serif 4* (variable, optical size): заголовки, цитаты, цифры. Редакционный голос.
- *Onest* (variable): интерфейс, текст, метки. Институциональный голос.

| Роль    | Размер (fluid)       | Интерлиньяж |
|---------|----------------------|-------------|
| H1      | 42 → 96 px, serif    | 0.98        |
| H2      | 34 → 68 px, serif    | 1.04        |
| H3      | 22 → 30 px, serif    | 1.15        |
| Lead    | 19 → 25 px           | 1.45        |
| Body    | 16 → 18 px           | 1.6         |
| Label   | 12 px, uppercase, +0.12em | 1.4    |

Ширина текстовых колонок — 44–62 ch.

**Цвет:** бумага `#F2EFE9` / `#E9E5DD`, графит `#14171A`, ночные секции `#15191D`, единственный акцент — сургуч `#A63A24`.

**Сетка:** контейнер 1440 px, 12 колонок (4 на мобильном), gutter 24/20/16 px, поля 40/28/20 px.

**UI:** прямоугольные кнопки (радиус 2 px) с заливкой слева направо на hover; тонкие линии‑разделители; нумерация секций `01–08`; sticky‑заголовки в колонке слева.

**Движение:** fade + сдвиг 18 px при появлении, раскрытие аккордеонов через `grid-template-rows`. Всё отключается при `prefers-reduced-motion`.

**Ритм страницы:** Hero на весь экран → спокойный «О нас» → плотная сетка принципов (на тоне) → editorial-список кейсов с одним тёмным избранным → мозаика отзывов → типографская пауза → тёмный блок процесса → компактный FAQ → контрастный CTA в цвете акцента.
